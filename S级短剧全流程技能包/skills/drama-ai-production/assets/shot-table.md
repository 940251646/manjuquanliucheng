# 全剧分镜执行模板

从完整正文和分集大纲生成；每季每集各复制一份，从 `EP001` 覆盖到约定的最后一集。先按[资产版本模板](asset-version-tables.md)完成 `production/每集资产使用清单.md`，再写本集全部场次和镜头。镜头不得引用清单外的资产变体；仅出现在一个场号的道具保留在逐场道具表，不建长期 P 本体。

## EP001 分镜索引

正文场号：〔EP001-S01、...〕　分镜覆盖场号：〔...〕　正文/实读时长：〔秒〕　分镜计划时长合计：〔秒〕

| 镜头ID | 正文场号/节拍 | 叙事任务 | 计划秒数 | 对白覆盖类别 | C/L/P变体@r与T编号 | 下一镜切点 |
|---|---|---|---|---|---|---|
| EP001-S01-SH01 |  |  | 30 | none/OTS/shot_reverse/other |  |  |

未指定时每条分镜的计划基准是 30 秒；对白、动作、证据、反应或状态转换需要更快切换时，拆成独立 SH 镜头并据实填写秒数，不把多个切口伪装成一个连续镜头。

## 逐镜卡片（每个 SH 复制）

### EP001-S01-SH01

| 字段 | 内容 |
|---|---|
| 正文依据与故事时间 | 〔EP001-S01、B编号；故事时间；现实/回忆/闪前；正文动作/对白位置〕 |
| 叙事任务与时长 | 〔本镜新增的信息、行动或情绪变化〕；`duration_seconds: 30`（按实调整）；拆镜理由/下一镜切点：〔...〕 |
| 人物表演逻辑 | 〔C编号：眼前目标→刺激/阻力→身体先反应→压住或改变策略→符合性格与情境的微动作→行动后果；视线落点〕 |
| 场景与人物 | 〔L本体-V@r、故事时间/光线/出入口；出镜C本体-V@r、服装妆发发饰、站位、关系及当下状态〕 |
| 道具与状态转换 | 〔P本体-V@r或逐场一次性道具、持有人/左右手/位置；动作前后状态；T编号〕 |
| 起始帧画面描述 | 〔具体可见画面；有人物时写景别、画面左右及前中后站位、姿态、手部、视线、道具关系〕 |
| 景别 | 〔景别及转变；过肩/双人/插入等镜头类型另写，不以“广角”代替景别〕 |
| 机位与视角 | 〔机位高度、角度、朝向、轴线；过肩前景是谁；POV归属和视线落点〕 |
| 运镜 | 〔固定/推/拉/摇/移/升降/跟/旋转/变焦等；方向、速度、停顿点、叙事动机〕 |
| 构图 | 〔主体、前中后景、留白、遮挡、引导线、人物视线方向〕 |
| 焦段与光学 | 〔焦段mm或等效视角、景深/焦点变化；与场景空间一致〕 |
| 画面与声音 | 〔动作和对白/心声/旁白/系统音的先后、同步/错位/静默点；准确台词或正文引用〕 |
| 音效与音乐 | 〔环境、脚步/衣物/道具等动作音、音乐入退及收音主体；无则写“无”〕 |
| 对白覆盖类别 | 〔有无可听对白；有则 `OTS`/`shot_reverse`/`other`；正反打写对应镜头ID与轴线，非对白记 `none`〕 |
| 人物动态/反应特写 | 〔对应镜头ID或本镜内的真实表演变化；重要情绪转折写触发、眼神/呼吸/手部等可见结果〕 |
| 结束帧画面描述 | 〔有人物时再写景别、站位、姿态、手部、视线、道具持有与情绪结果；下一镜接续动作〕 |
| 连续性与制作 | 〔C/L/P版本和妆发/光线/伤痕/门窗/轴线/声音接续；F/N线索；提示词临时展开来源；素材路径或待制作状态〕 |

镜头实际生成时临时展开“本体完整提示词 + 继承链变体差量 + 已预设的可选风格 + 本镜动作/构图”；未预设风格则省略风格段，不将展开后的全文回写到变体提示词。文字设计阶段标明设计修订及尚无素材，实际制作时绑定真实文件，保留历史 r 号。

## EP001 覆盖与验收

| 核对项 | 计算/证据 | 结果与待修 |
|---|---|---|
| 场次覆盖 | 正文场号集合 − 分镜场号集合＝〔缺失场号〕；每镜有正文依据 |  |
| 时长覆盖 | `sum(duration_seconds)`＝〔秒〕；与本集实读/计划〔秒〕差值〔秒〕；本季累计〔秒〕，上限8400秒 |  |
| 对白镜头比例 | 承载可听对白的实际SH镜头数 `D=〔〕`；其中过肩或成对正反打 `Q=〔〕`；`Q/D=〔〕%`，`D>0`时须≥65%；纯心声不计D |  |
| 景别和运镜变化 | 相邻镜头重复景别/运镜及叙事理由；动作场的空间交代镜头 |  |
| 动态与反应特写 | 转折点/触发/特写镜头ID；没有特写的明确原因 |  |
| 资产绑定 | 本集资产清单与逐场、逐镜C/L/P-V@r一致；一次性道具保留逐场记录 |  |
| 跨镜接续 | 逐镜结束帧→下一镜起始帧的动作、站位、妆发、道具、光线、轴线与声音 |  |

若 `D=0`，比例写“不适用”，仍核查心声与画面因果。每季另汇总全部集数、分镜覆盖集数、累计秒数和对白镜头比例；不足项列具体集场镜头，不以“已规划”代替完成。
