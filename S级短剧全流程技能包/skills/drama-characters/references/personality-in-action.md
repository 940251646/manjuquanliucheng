# 人物性格如何进入正文

用户要的是能被观众感受到的具体人物，而非只在人设表出现的形容词。核心人物与反复出场配角建立行为规则；一次性角色保留当前诉求、应对方式与边界即可。参考中的姓名、职业、关系及整套性格组合不自动进入新项目。

## 1. 从性格标签转为条件化的行动

把“幽默、独立、温柔、强势”等标签展开成：

```text
在什么刺激下 → 他怎样理解这件事 → 要保护什么
→ 习惯用什么方法应对 → 嘴上、心里、行动有何差别
→ 对方怎样回应 → 局势或关系留下什么后果
```

性格是选择倾向，不是固定情绪。冷静的人也会急，温柔的人也会拒绝，好胜的人也会认输；写清触发条件、压抑过程与付出的成本，反差才能成立。

## 2. 性格行为卡

详细卡写入 `02-characters.md`；`canon/characters.md` 保留当前有效规则、阶段变化与该卡索引。复用已有 C 编号，不另建人物。

| 字段 | 要回答的问题 |
|---|---|
| 主导倾向 | 当前最影响选择的两三项性格是什么？避免堆积同义形容词 |
| 表里反差 | 别人怎样看他；他最想藏住的需求或不安是什么？确有依据再设反差 |
| 价值排序 | 面子、关系、钱、事实、秩序、自由等发生冲突时，先保哪一个？ |
| 敏感点与触发 | 什么具体言行会刺痛、安抚或激怒他？与哪段经历有关？ |
| 防御与惯用策略 | 开玩笑、先核实、抢着承担、退让、转移话题、谈条件，分别何时使用？ |
| 情绪表达 | 会直接说、故意掩饰还是转为行动？压力增大时怎样变化？ |
| 对白与心声 | 用词、句长、提问方式、回避的话题；对外表达和内心判断如何错位？ |
| 情境动作 | 当前物件、服装、伤势、职业和空间怎样影响动作？动作想达到什么目的？ |
| 关系差异 | 面对陌生人、亲近者、上级、对手时，策略怎样变化？ |
| 优势与代价 | 同一倾向什么时候帮他解决问题，什么时候使他付出损失？ |
| 底线与破例 | 通常守住什么；什么压力可能促成破例，破例后怎样承担结果？ |
| 阶段发展 | 起初的应对方式、改变它的事件、后来仍保留的性格底色是什么？ |

这些是编剧决策工具，正文不插入整张人物分析表。不是每个人都需要创伤、秘密或成长；坚定型人物可以保持原则，同时学会更有效的行动方式。

## 3. 用三种情境检查辨识度

核心人物用“受挫、利益诱惑、亲近者求助”各推演一次；已有剧情可直接提供证据，篇幅较小的任务只做相关一项。

比较人物的**首选策略、守护对象和愿付代价**，而非只比较他们说什么词。同一事件可以有相同情绪，行动路径仍应体现个人经历和关系位置。

| 同样被当众质疑 | 行动倾向 | 易付出的代价 |
|---|---|---|
| 表面松弛、内里好胜 | 先用自嘲保住场面，再争取一次当场验证 | 玩笑被当作敷衍，转身又为争一口气冒进 |
| 独立干练、不善求助 | 先切断损失、整理事实，把问题留给自己处理 | 拒绝及时协作，压缩了核实与休息时间 |
| 温和体贴、有明确底线 | 先给人台阶，涉及原则时清楚提出条件 | 为照顾别人迟说关键事实，必须承担迟说的后果 |

此表是三种不同假设，不要求实际项目采用这三类，也不按性别分配。

## 4. 场景落地：性格让事件往下走

每场开写前，只提取在场人物当前相关的性格字段：

```text
人物C编号／当前目标与知情范围／触发点
／首选策略／对话对象／表里表达／动作与后果
```

先写人物选择，再写对方回应和后果。正文中避免用“他是个嘴硬心软的人”概括掉整场；让实际动作与语言承担证据。内心独白可以暴露矛盾，却只代表人物理解，其他角色凭实际可听可见信息反应。

### 示范：不是一句“外冷内热”

既定事实：两人负责同一批设备检修。夜班快结束，新人把责任记录签成自己的名字，想替带班者承担延误。带班者要强，重视事实，习惯用工作安排表达关心。

**标签式草稿**：带班者外冷内热，见新人受委屈，很感动，决定帮忙。

**正文示范**：

新人把记录推过来，手指还压在签名末尾。

带班者看一眼，没接笔。她把表格转回去，点住“复核人”那一栏。

带班者：“谁复核的，就写谁。别替我签。”

新人缩回手：“我想着，您已经忙了一夜……”

她刚拧开的保温杯停在半空。两秒后，杯盖放到新人手边，杯口转开。

带班者：“去吃早饭。回来再把经过补齐。”

【带班者·内心】差点连他也拖进来。

新人没走，指了指表格背面：“还有一处，我想先给您看。”

她把准备收走的表格重新放平，给他让出桌边的位置。

**证据解释**：纠正签名体现责任边界；关心落在工作安排与杯子动作里；内心承认压力，对外仍简短；让出位置是一点接受帮助的变化。新人的发现尚待核验，下一步来自他的自主行动，不凭空宣布真相。保温杯出现与转移写入实际道具状态；示例不固定进任何新项目。

## 5. 对手与配角也有自己的活法

- 反复出场配角有自己的目标、偏好、维护的利益与拒绝理由，而非只负责夸主角或送线索。
- 对手怎样争取资源、应付失误、面对更强者、解释自身行为，都要有个人逻辑；不要求每个对手都有温情面或洗白结局。
- 两个同样讲义气的人可以因方法冲突：一人坚持当面维护，一人想先留下证据。两者相撞才产生具体关系戏。
- 性格首先服务真实人物；同场角色不必全都说金句、都藏反差、都抢高光。复杂度按戏份配置。

## 6. 连续性、成长与反常

用 `刺激 → 旧习惯选择 → 实际代价 → 认识或关系变化 → 新选择` 组织发展。新选择先在小事中露出，再在重要节点检验；跨季沿用已经发生的变化。

人物反常时区分成长、伪装、短时压力和写作漂移。前三者需有动机、知情范围、触发及后果证据；为推进剧情临时改性格则重写相关行动。成长后的角色仍保留自己的声音与底色，例如嘴贫者关键时刻学会停下玩笑，而非突然变成另一套人格。

## 7. 正文审查

人物卡只算设计，已写正文中的证据才算落地。审稿逐项问：

1. 遮住名字后，能否依据策略、关切对象和说话方式区分主要人物？这是诊断方法，不要求每句都可独立识人。
2. 标签是否至少有具体行动支撑？只写“冷笑、握拳、眼眶红”仍缺动机与选择。
3. 同一性格是否既有作用，也存在适用边界或代价？按人物路线安排，不强求每集一利一弊。
4. 关键场面能否定位 `性格倾向 → 选择 → 他者回应 → 后果`？后果进入关系、资源或 N 事件节点。
5. 角色是否为反转临时愚化、为笑话牺牲底线、为煽情突然换说话方式？
6. 性格稳定是否被写成动作循环？保留应对逻辑，随情境变化表达。

证据复用人物模板中的表格与项目 `review/evidence.md`，列 C编号、集场、触发、动作/对白/心声、后果、阶段变化和待修项；计划与已写分别标记。无需给每句台词附性格说明。
