# 结构重构与统一评分指南

## 五步落地

1. **机制交叉**：每份来源独立拆解，只抽取公共情绪、信息差、回报机制；多来源可选，不拼接原作连续事件。
2. **功能与表达分离**：参考集卡只留功能，姓名、关系组合、具体行动与独特顺序进入禁带清单。
3. **新因果建模**：世界/制度、人物关系、核心利益共同建立新选择与后果；换地域、职业、金额不等于完成重构。
4. **场景与资产落地**：重新设计冲突动作、见证人、空间路线、道具证据、服装妆发与场景变体，绑定逐场版本。
5. **语言与声音重建**：按新人物的职业、目的、潜台词及处境写对白、心声和细微动作，再做证据审查。

检查“删除参考材料后，新作能否仅靠自身正典、因果图和资产账解释”。新作节拍可以改变次序、合并或分拆；具辨识度的事件排列、信息释放与回报组合也属于重构对象。

## 唯一评分体系

评分与参考证据、新作证据成对。评分是编辑工具，未经过统计标定；它不等同于客观原创百分比、法律判断或发布结果保证。两部以上融合也不自动消除单部或组合表达重合。

### 表达量表 0—5 锚点

| 分值 | 证据标准 |
|---:|---|
| 0 | 材料充分可比，未发现具体表达对应；共有类型惯例单列 |
| 1 | 少量通用相似，人物选择、实现细节及后果明显独立 |
| 2 | 局部具体对应，但关键因果不同 |
| 3 | 多处具体对应，角色功能或动作—结果路径持续接近 |
| 4 | 高辨识组合相近，关系、事件、物件或措辞成套对应 |
| 5 | 核心表达或独特连续结构高度对应，主要变化是表层命名 |
| N/A | 原作或新稿材料缺失、尚未创作、证据不足，暂不评分 |

`0` 只用于充分观察且未发现对应；缺失永远用 `N/A`。

### 机制相似度：描述型，不进入原创度指数

| 维度 | 权重 |
|---|---:|
| 题材与情绪承诺 | 20 |
| 情绪曲线 | 25 |
| 节拍功能 | 20 |
| 信息释放机制 | 15 |
| 回报机制与顺序 | 20 |

机制高相似只描述研究结果；若具体排列形成独特表达，转入表达维度与识别簇审查，不用“机制”标签掩盖。

机制量表单独按功能吻合程度定分：0=已比较且机制不同，1=少量通用功能，2=局部同类，3=多段功能与强弱走势相近，4=大部分机制组织相近，5=所评范围机制几乎一致；未知用 N/A。机制同类不直接计成具体表达重合。

### 表达相似度：唯一六维计分表

| 维度 | 权重 | 重点证据 |
|---|---:|---|
| 人物与关系 | 20 | 身份组合、目标动机、关系历史、知情网络 |
| 事件因果链 | 25 | 独特事件、因果边、选择后果、连续顺序、伏笔路径 |
| 场景与调度 | 15 | 空间布局、见证人、关键动作顺序、标志镜头 |
| 道具与规则 | 10 | 专属设定、能力限制、物件用途/交接/证据组合 |
| 台词、旁白、心声 | 15 | 独特措辞、金句、问答模板、声音视角与声纹 |
| 结局与反转依据 | 15 | 高潮选择、反转证据、最终代价、关系落点 |

每个来源 `SRCxx` 单独填表，权重合计 100：

```text
维度贡献 = 权重 × 评分 / 5
单源表达相似分 = Σ(六维贡献)
整体表达相似分 = max(各来源表达相似分)
内部原创度指数 = 100 - 整体表达相似分
```

完整单值只适用于六维均有足够双方材料、审查范围已完整读取的情况；结果只对应已声明的审查范围。

### 不完整材料与方向卡

候选大纲尚无对白、逐场调度或确定结局时，对应维度填 `N/A`；想象中的独立台词不作为 0 分证据。每个来源记录：

```text
observed_weight = 已评分维度权重之和
coverage = observed_weight / 100
known_contribution = Σ(已评分维度的权重 × 评分 / 5)
expression_interval = [known_contribution, known_contribution + 100 - observed_weight]
```

这是缺失维度从 0 至 5 取值形成的理论界限，不是概率置信区间。例如仅人物与事件可比，分数为 1 和 2，则覆盖率 45%，已知贡献 14，区间 [14,69]；缺失台词依然为 `N/A`。

已观察维度只能估 `a—b` 时，按 `w×a/5` 至 `w×b/5` 汇总并写判断理由。参考缺集时另报来源阅读覆盖率；维度覆盖率不掩盖来源缺口。

多来源区间：总体下界为各来源下界最大值，上界为各来源上界最大值。方向卡展示已评维度、覆盖率、未评项和区间，不展示全稿原创度精确百分比；`originality_index=null`。用户需要区间时，用 `[100-相似上界,100-相似下界]` 并标“当前证据边界内的编辑指数区间”。

## 唯一数值门禁

| 表达相似分 | 编辑动作 |
|---|---|
| <25 | 进入下一阶段审阅，仍检查识别簇与范围 |
| 25≤分数<40 | 修改高分维度后重新审查 |
| ≥40 | 回到方向或根基重构，暂缓正文扩写 |

区间跨门槛标 `pending_evidence`，补齐再判定。门槛是项目内返工设置，未作法律标定。任一独特表达簇尚未处理时，保留人工返工任务；低总分不等于该项已消除。

### 各阶段怎样推进

- **方向门**：检查已有目标、关系、利益、因果与结局设计，发现的对应先修；缺少尚未创作的台词或逐场调度，仅标待评和区间，用户仍可选择方向。
- **样稿门**：用户已选定，且已知结构问题已处理后，允许写独立前三集补充证据。对白等待评项随实际样稿复核；未知项不预填低分，也不因尚无正文而锁死写作。
- **扩写门**：按实际已写范围复核各维度与高识别簇；高风险事件链先返工，再展开后续批次。来源材料缺口如实保留，结论仅覆盖已读范围。
- **终稿门**：对应交付范围已有完整正文、需比较的参考范围已读、六维已实质审阅、已发现识别簇已处理，才给单值与本轮编辑通过结论。参考不全时仅报告局部结果及未覆盖范围。

## 八项诊断清单（不另计分）

以下项目定位证据，不建立第二套权重、原创度或门槛：独特短语/专名/金句；独特事件链与同序组合；因果图与伏笔回收边；人物目标与关系网；世界规则与能力限制；场景—物件—揭示组合；对白声纹与心声视角；标题、高潮选择及结尾视觉。

### 单源与跨来源检查

逐来源采用最高单源，不按均值冲淡。另建跨来源识别簇表：`cluster_id | 来源片段集合 | 新作连续链 | 可识别对应 | 重构动作 | 状态`。即使每个来源只贡献一段，组合仍可保留多段独特表达；跨源检查独立列任务，不因最高单源低而跳过。

### 证据条目

```yaml
source_id: SRC01
source_evidence: SRC01-EP007-S02
new_evidence: S01-EP003-S01
dimension: 事件因果链
score: 3
reason: 相同位置以相似物件迫使主角公开秘密，选择后果仍近似
change: 从新利益设计行动、证据来源和后果
status: open|revised|closed
confidence: low|medium|high
```

未读参考、未写新稿和未经核对内容都进 `unobserved`。每次改稿保留旧证据、动作与复核结果；每季独立计算，系列正典延续不抵消本季问题。
