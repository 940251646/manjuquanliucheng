# 方向选择与重构启动单

默认 6 张，至少 3 张；每张详细卡完整填写题材、主线和架构。用户可扩展数量。

## 详细方向卡（A—F逐张填写）

```text
方向编号/工作标题：
题材/时代/地域/情绪承诺/目标观众：
一句话故事：
主线目标/核心利益/前期对手策略：
支线目标/与主线的因果交点/回收位置：
人物新关系与价值冲突：
能力或资源边界/代价：
全季架构：入局→首轮回报→中段转向→代价升级→高潮选择→季末结果
前三集钩子与各集局势变化：
制作与资产难点：
季数/本季集数/每季时长范围/后续季入口：
采用的抽象机制/来源编号：
舍弃的具体表达与新因果证据：
```

## 用户选择

```yaml
reference_rebuild:
  reference_phase: options
  selected_direction_id: ""
  combine_mechanisms: []
  avoid_elements: []
season_count: 1
episode_counts: [120]
active_season: S01
```

用户填写编号或明确组合；抽象机制可组合，原作专名、独特关系、连续事件、专属物件与金句留在禁带清单。未选定时保留候选；选定后更新 `reference_phase=selected`。每季仍执行不超过 140 分钟的项目边界。
